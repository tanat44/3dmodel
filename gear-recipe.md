# Gear recipe
- Use pressure angle 14.5 deg for all 3d printed gear (20 deg create too much friction)
- Use gear workbench in Freecad (do not use involute profile)

## External gear
Module: 1.0
Tolerance backlash = 0.2
Tolerance head = -0.2

## Internal gear
Module: 1.0
Tolerance backlash = 0.2
Tolerance head = -0.4
Head fillet = 0.4

## Legacy involute profile

### External gear
Ideal module = 1.0 use this value for radius calculation
Actual drawing module = 0.98 to give enough clearance
This rule is tested with 10T and 30T
